It identifies the site in Cloudflare's dashboard and is visible in the page source by design, so it lives in hugo.toml rather than in a build secret. Guarded twice over: no token configured means no script, and development builds never emit it, so `hugo server` cannot pollute the numbers. The old Jekyll setup did the same by testing window.location.hostname at runtime; deciding at build time is cheaper and cannot be wrong. */}} {{- if hugo.IsProduction -}} {{- with site.Params.cloudflareAnalyticsToken -}} {{- end -}} {{- end -}}
