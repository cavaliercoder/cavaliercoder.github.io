Readers sign in with GitHub and comment there; nothing is stored by this site, and there is no database, no moderation queue and no third-party account to hold. Deleting a discussion deletes the thread. It sets no cookies for readers who only read, so the site still needs no consent banner — the same reason Cloudflare Web Analytics was chosen. Two things have to be true on the GitHub side, and neither is expressed here: Discussions must be enabled on the repository, and the giscus App must be installed on it. Without the App, the frame renders but posting fails. Threads live in the Announcements category because only maintainers may open a discussion there by hand; every other category lets anyone start one, which would put unmapped threads alongside the mapped ones. Mapping is by pathname, so a thread is bound to the URL rather than to the title — posts get retitled, and the handful with a custom `url` in front matter still map cleanly. The cost is that changing a post's URL orphans its thread, which is why the Jekyll-era permalinks are preserved in hugo.toml. Not gated on `hugo.IsProduction`, unlike the analytics beacon: comments are worth seeing while writing, and a stray comment from `hugo server` lands in the same thread as one from the live page rather than anywhere unexpected. */}} {{- if ne .Params.comments false -}} {{- with site.Params.giscus -}} {{- if and .repo .repo_id .category .category_id -}}
